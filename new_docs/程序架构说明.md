# InstructionX 程序架构说明

## 1. 项目概述

InstructionX 是一个基于 **PySide6** 的插件化桌面应用程序，采用模块化设计，支持动态加载插件。用户可以通过添加插件来扩展应用功能，插件之间可以通过 DataProvider 进行数据通信。

### 技术栈

| 组件 | 技术 |
|------|------|
| UI 框架 | PySide6 (Qt for Python) |
| 编程语言 | Python 3.x |
| 数据存储 | JSON 文件 |
| 插件机制 | 动态导入 + 接口抽象 |

## 3. 核心模块说明

### 3.1 主入口 (main.py)

程序入口点，负责初始化应用和主窗口。

```python
# main.py
import sys
from PySide6.QtWidgets import QApplication
from ui.main_window import InstructionXMainWindow
from utils.themes import set_light_theme

def main():
    app = QApplication(sys.argv)
    app.setApplicationName("InstructionX")
    app.setOrganizationName("InstructionX")

    set_light_theme()

    window = InstructionXMainWindow()
    window.show()

    sys.exit(app.exec())
```

### 3.2 主窗口 (ui/main_window.py)

管理整个应用的主界面布局，协调 SkillsPanel 和 WorkArea 的交互。

```
┌────────────────────────────────────────────┐
│  菜单栏 (文件/编辑/用户中心/帮助)          │
├────────────────────────────────────────────┤
│  SkillsPanel (技能面板) 高度: 120-150px   │
├────────────────────────────────────────────┤
│  分割线                                    │
├────────────────────────────────────────────┤
│  WorkArea (工作区) 可伸缩                   │
│                                            │
│  "点击上方技能按钮，在此处显示插件功能"     │
│                                            │
└────────────────────────────────────────────┘
```

### 3.3 技能面板 (ui/skills_panel/panel.py)

显示可用插件的技能按钮，支持分类显示（官方功能/第三方功能）。

**主要特性**：
- 使用 `QTabWidget` 分为两个标签页
- 横向滚动显示技能按钮
- MS Office 风格：图标在上（36x36），文字在下
- 点击触发 `skill_clicked` 信号

### 3.4 工作区 (ui/work_area/work_area.py)

显示激活插件的内容区域。

**主要特性**：
- 接收 SkillsPanel 的点击事件
- 显示插件 Widget
- 支持清空工作区

### 3.5 插件管理器 (core/plugin/manager.py)

核心的插件管理系统，负责插件的加载、排序和 API 管理。

**核心功能**：
- `load_plugins()` - 扫描并加载插件
- `get_all_plugins()` - 获取所有已加载插件
- `call_plugin_method()` - 跨插件方法调用
- `get_plugin_api()` - 获取插件提供的 API

### 3.6 数据提供者 (core/data/data_provider.py)

应用的数据中枢，采用单例模式。

**核心功能**：
- 数据持久化（JSON 文件）
- 内存缓存
- 命名空间隔离（PRIVATE / PUBLIC）
- 发布/订阅模式
- 资源文件管理

```

    │
    ▼

    │
    ▼
```

## 6. 关键设计模式

### 6.1 单例模式

**PluginManager** 和 **DataProvider** 都采用单例模式，确保全局唯一实例。

```python
class PluginManager:
    _instance = None
    _initialized = False

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```

### 6.2 抽象基类模式

**IPlugin** 接口定义了插件必须实现的方法：

```python
class IPlugin(ABC):
    @property
    @abstractmethod
    def plugin_name(self) -> str:
        """插件名称"""
        pass

    @abstractmethod
    def _create_widget(self, parent=None, data_provider=None) -> QWidget:
        """创建插件 UI 控件"""
        pass

    def get_widget(self, parent=None, data_provider=None) -> QWidget:
        """获取插件控件（带缓存）"""
        pass
```

### 6.3 发布/订阅模式

**DataProvider** 实现了插件间的解耦通信：

```python
# 订阅数据变化
data_provider.subscribe(
    subscriber_id="my_plugin",
    target_plugin_id="task_manager",
    target_key="tasks",
    callback=self.on_tasks_changed
)

# 发布数据更新
data_provider.publish(
    publisher_id="my_plugin",
    key="new_task",
    value={"title": "新任务"},
    namespace="PUBLIC"
)
```

## 8. 总结

InstructionX 采用分层架构设计：

| 层次 | 职责 | 关键组件 |
|------|------|----------|
| **UI 层** | 用户界面展示 | SkillsPanel, WorkArea |
| **业务层** | 插件管理与调度 | PluginManager |
| **数据层** | 数据持久化与通信 | DataProvider |

这种架构的优势：
- **高内聚低耦合**：各层职责明确
- **可扩展性强**：通过添加新插件扩展功能
- **易维护**：模块化设计便于调试和维护
- **灵活性高**：插件间通过 DataProvider 解耦通信
