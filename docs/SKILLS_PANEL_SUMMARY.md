## 使用方法

### 启动应用
```bash
python main.py
```

### 使用技能面板
1. 应用启动后，顶部显示 SkillsPanel 工具栏
2. 工具栏下方是工作区
3. 点击"官方技能"或"第三方技能"标签页切换
4. 点击任意技能按钮，插件功能会显示在下方工作区
5. 窗口大小保持固定，只能通过拖拽边缘手动调整

### 添加新插件
1. 在相应目录创建插件文件夹
2. 创建 `__init__.py` 并实现 `IPlugin` 接口
3. 重启应用或调用 `refresh_skills()`

详细步骤请参考 `docs/SKILLS_PANEL_GUIDE.md`
